1. 내 카카오 앱

연결 상태를 불러오는 중

카카오 앱 관리 열기
  1. 본인 앱을 만들거나 기존 개인 알림 앱을 선택합니다.
  2. 카카오 로그인 사용 설정을 ON으로 저장합니다.
  3. 카카오 로그인 → 동의항목에서 카카오톡 메시지 전송 talk_message을 선택 동의 또는 이용 중 동의로 설정합니다.
  4. 앱 → 플랫폼 키 → REST API 키에 아래 콜백 주소를 등록하고 REST API 키와 클라이언트 시크릿을 복사합니다.

새 REST API 키는 시크릿이 기본 활성화되어 있습니다.

기존 연결을 다른 앱으로 교체

3. 카카오 템플릿 연결

메시지 템플릿 도구 열기
기본 알림 연결
  1. 연결한 앱에서 사용자 정의 피드 A형 템플릿을 만듭니다.
  2. 사용 목적은 카카오톡 공유, 전달 허용은 불가로 설정합니다.
  3. 제목과 본문을 켜고 제목에 ${TITLE}, 본문에 ${TEXT}를 입력합니다.
  4. 이미지, 버튼, 헤더, 프로필, 소셜과 아이템은 끕니다. 공통 링크와 제목/본문 링크도 사용 안 함으로 설정합니다.
  5. 저장한 템플릿의 ID를 아래에 입력합니다.
사진 알림 연결

사진용은 텍스트 템플릿을 복제해 이미지 1장을 켜고 ${IMAGE} 인자를 설정합니다. 버튼과 링크는 끈 상태로 저장합니다.

링크 도메인 등록

링크 버튼의 목적지 도메인을 앱의 제품 링크 관리에 등록한 뒤 입력합니다.
